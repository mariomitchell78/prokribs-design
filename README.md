# ProKribs App Design Prototype

Clickable prototype of the ProKribs mobile app: 35 screens covering signup and verification, search, Stripe booking, living in the home, hosting, team housing, admin, account settings, and light mode.

Open index.html to see every screen, or Main.html to start the flow.

Names, prices and photos are sample data. This is a design prototype, not a live product.

The tools folder has the script that exports the screens from the design canvas.
